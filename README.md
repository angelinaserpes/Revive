## About

Revive makes sustainable shopping simple: browse and buy eco-friendly and recycled products in one place. It was built for the **Product Design (HSSM301)** course at FCRIT, Mumbai, and covers the full journey from design to a working website and a mobile app.

## How it was built

1. **Designed** the UI in Figma and generated the front end with **Figma Make**
2. **Built** as a React web app
3. **Deployed** the website on **Vercel**
4. **Packaged** the site as an **Android app (APK)** with **Median**

## Tech stack

React 19 · TypeScript · Tailwind CSS v4 · Vite 8 · Vercel · Median (Android)

## Run locally

```bash
git clone https://github.com/angelinaserpes/Revive.git
cd Revive
pnpm install
pnpm dev
```
